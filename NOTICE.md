# Upstream provenance

The host connection implementation is derived from
`deepseek-ai/deepseek-harness`, package
`@deepseek-ai/dsh-client-connection`, at commit
`47f943859bef60e4160492346772ded9b24f765a` and is maintained as a minimal
authorization patch for the `0.1.0-rc.6` wire contract.

The browser bundle is generated from the official
`@deepseek-ai/dsh-client-connection@0.1.0-rc.6` artifact with only its module
registration id changed to this package name.
